# Lecture 08 reading guide

- [InstructGPT (Ouyang et al., 2022)](https://arxiv.org/abs/2203.02155): Figure 2 and Sections 3.1–3.3 for the three datasets, reward model and PPO/PPO-ptx. Ask which distribution each evaluation measures.
- [PPO (Schulman et al., 2017)](https://arxiv.org/abs/1707.06347): Section 3 supplies the policy update developed in Lecture 09.
- [Course post-training guide](../../docs/rl-posttraining-and-agents.md): use the index for further context; the lecture notes define the required notation.

The demonstrations, numerical examples and chart are authored teaching examples.
Reading a full paper's compute scale does not create a course compute requirement.
