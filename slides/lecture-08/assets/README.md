# Lecture 08 asset provenance

Charts are editable Plotly specifications generated by `build_assets.py`.
Five original diagrams have paired SVG and Excalidraw files generated from
the same geometry and text by `build_diagrams.py`.
The shared slide framework supplies fonts, colors, and rendering libraries.
The Python helpers use only the standard library. They group and score values
in memory; they do not delete files or call external services.

## Historical measurements

`historical-shortcuts.json` redraws **Figure 4** of
[HellaSwag, Zellers et al., 2019](https://arxiv.org/abs/1905.07830), also present
in Spring PPTX slide 17 (`image16.png` in its embedded media).

| BERT-Large accuracy (%) | Default | Ending only | Shuffled | Shuffled + ending only |
| --- | ---: | ---: | ---: | ---: |
| SWAG | 86.7 | 74.8 | 77.0 | 60.4 |
| HellaSwag | 46.7 | 41.4 | 36.2 | 31.6 |

The models were trained and evaluated for each condition. Ending-only omits
context; shuffling changes token order within endings. The native replot uses a
zero baseline and preserves all eight values. These are dated paper measurements,
not present-day model rankings. No source screenshot is embedded in the deck.

## Synthetic teaching fixtures

The pipeline, extraction, MinHash, duplicate-family, and mixture diagrams are
course-authored, not traced paper figures. Their editable sources are adjacent
`.excalidraw` files. `data_quality.py` supplies the corresponding calculations:

- MinHash sets `{a,b,c}` and `{b,c,d}` have Jaccard `1/2`. The four displayed
  orders give two signature matches; enumerating all 24 permutations gives 12.
  Under independent ideal rows, two bands of two rows yield candidate probability
  `7/16`. The [FineWeb author report](https://huggingfacefw-blogpost-fineweb-v1.static.hf.space/index.html)
  provides the real-pipeline connection; the tiny implementation is instructional.
- The family graph uses shingle sets A `{1,2,3,4}`, B `{1,2,3,4,5}`, and
  C `{2,3,4,5}`. Edges A–B and B–C pass threshold `0.75`; A–C does not.
  Connected components define split groups, not automatic deletion decisions.
- A `9M/1M` English/Chinese pool and `60M` processed-token budget yield
  `6/6` expected passes with natural weights and `5/15` with square-root weights.
  These are token weights, with uniform within-source sampling with replacement
  and packing overhead ignored. They are not training measurements.

`toy-documents.json` contains six authored English records, with an accent and
line-ending example. The exact comparison uses NFC, LF line endings, and stripped
outer whitespace; it preserves case and internal spacing. The near-duplicate
example uses whitespace word bigrams, not a model tokenizer.

`evaluation.py` constructs the 100 clean paired outcomes explicitly:

| Outcome | Count |
| --- | ---: |
| Both correct | 50 |
| A only correct | 10 |
| B only correct | 14 |
| Both incorrect | 26 |

The additional 20 exposed outcomes contain 19 successes for A and 11 for B.
Their exposure status is an assumed independent audit finding. They are a
counterexample about evaluation composition, not an estimate of memorization.
The interactive chart's two states come from these same values.

`bootstrap.json` bins 5,000 paired resampled accuracy differences from the clean
items. Seed: `20261028`. Percentiles use linear interpolation at indices
`(draws−1) × q`. The estimate is `0.04`, with endpoints `−0.05` and `0.13`.
Multiply by 100 for percentage points. This illustration conditions on fixed
models/prompts and assumes independent items. It is not a posterior distribution.

`teaching-results.json` records those checks plus the HumanEval-style pass@k
calculation for ten attempts and two successes. The classroom completion log
probabilities, prompt-sensitivity table, language-mixture table, and token budgets
are authored numbers, not inference or training measurements.
