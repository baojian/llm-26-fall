# Lecture 09 assets

`ppo-clipping.json` plots the exact PPO clipped surrogate with epsilon=0.2 and advantages +2/-2. It is an analytical illustration, not model performance. [PPO Equation 7](https://arxiv.org/abs/1707.06347) defines the function. Notebook E02 checks its values and which branch applies.

The instructor supplied *Policy optimization for LLMs: REINFORCE, PPO, GRPO and DPO*, a 24-page PDF dated November 4, 2026. Its notation and derivation order inform the notes and slides. It is not redistributed here. Original explanations and synthetic exercises are supplied in Markdown and the notebook.
