# Contributions

Follow [the task instructions](../instruction.md). Add one UTF-8 JSON file,
`<your-lowercase-github-username>.json`, based on
[contribution-template.json](../contribution-template.json).

For a pair, use the first contributor's username for the filename and list
both usernames in `contributors`. The current progress board indexes files
by filename; the second contributor is credited in the file and PR, not
automatically as a separate board entry.

Keep downloaded artifacts and generated reports in the ignored `workspace/`
directory. Submit only your authored comparison file; the shared runner
supplies its measurements. Do not include A1 implementation code or reports.
