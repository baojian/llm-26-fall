# Lecture 01 activities

Build a shared resource that we can inspect together in class.

| Activity | Contribution | Time |
| --- | --- | --- |
| [Compare public tokenizers](tokenizer-comparison/instruction.md) | Predict, measure, and explain how two tokenizers handle the same text | About 45 minutes |
| [LLM-app survey](../../surveys/lecture-01/README.md) | Report which applications you use; any number of selections, including zero | About 5 minutes |

The tokenizer comparison is a voluntary, ungraded collaboration. Everyone
uses the same instructions. Its checked vocabulary counts can support the
[model table and timeline project](https://github.com/baojian/llm-26-fall/issues/154).
