One file per student, named `<github-username-in-lowercase>.py`. Use the username
of the account that opens the PR, not the profile display name. For example,
`OctoCat` submits `octocat.py`; GitHub does not lowercase filenames automatically.

A mismatched filename will not be accepted, even if the code passes. Correct it
by renaming the file in the same PR. See [the instructions](../instruction.md)
for the required `solve` function, predictions, personal cases, and explanation.
