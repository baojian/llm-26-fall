# Course Schedule and Class Periods

**Wednesdays, periods 6–8 (13:30–16:10)** in **HGX103, Handan Campus**, during
teaching weeks 1–16 of the first semester of the 2026–2027 academic year.

## Class periods

Fudan schedules classes in numbered 45-minute periods. Our course is listed as
**Wednesday, periods 6–8**, which means **13:30–16:10**.
